이야기시리즈 환경저장 경로는 /home/iyagi/.config/IYAGI-INC

### 이야기 시리즈

이야기에서 개발하는 프로그램과 도구입니다. 리눅스 판은 자유롭게 쓰고 나눌 수 있고, 윈도우 판은 MS 스토어로 배포합니다. 소스는 공개하지 않으며 각 저장소의 Releases 에 설치 파일이 있습니다.

#### 파일·문서·화면

- [FileIyagi](https://github.com/iyagicom/FileIyagi) — 파일 관리자. 2·3·4분할 화면, SFTP·SMB·FTP·WebDAV 연결, 파일 비교, 빠른 미리보기, 압축 파일 (Windows·Linux)
- [PDFIyagi](https://github.com/iyagicom/PDFIyagi) — PDF 편집기. 기존 글자 고치기, 서명·도장, 가림 처리, 자르기, 글자 인식(OCR), 스캐너(ADF) (Windows·Linux)
- [ClipIyagi](https://github.com/iyagicom/ClipIyagi) — 클립보드 기록 관리. 글자·그림 기록, 고정, 태그, 전역 단축키, 자동 붙여넣기 (Windows·Linux)
- [ScreenDrawIyagi](https://github.com/iyagicom/ScreenDrawIyagi) — 화면에 그리기. 펜·형광펜·도형·글자·이모지 도장, 발표와 강의용 (Windows·Linux)
- [VideoDownloadIyagi](https://github.com/iyagicom/VideoDownloadIyagi) — 브라우저에서 재생 중인 영상 저장. 확장 프로그램이 HLS/MP4 흐름을 찾고 앱이 병렬로 내려받으며 이어받기·화질 선택 지원. DRM 우회 없음

#### 바탕화면·시스템

- [PanelIyagi](https://github.com/iyagicom/PanelIyagi) — Ubuntu GNOME용 패널·작업 표시줄. 시작 메뉴, 트레이, 시계·달력, 포스트잇, 계산기, 빠른 설정
- [TaskIyagi](https://github.com/iyagicom/TaskIyagi) — 어느 리눅스 데스크톱에서나 쓰는 작업 표시줄·패널 (GNOME·KDE Plasma·XFCE·Cinnamon·MATE·LXQt·sway). 시작 메뉴, 트레이, 달력, 포스트잇, 다중 모니터
- [WindowIyagi](https://github.com/iyagicom/WindowIyagi) — 열린 창 목록과 제어(활성화·최소화·최대화·닫기). GNOME·KDE Plasma·wlroots
- [HangleIyagi](https://github.com/iyagicom/HangleIyagi) — 리눅스 Wayland/GNOME용 한글 입력기. 완성된 음절을 바로 입력하며 두벌식, 세벌식 390/최종, 사용자 배열 지원
- [HistoryIyagi](https://github.com/iyagicom/HistoryIyagi) — 터미널 명령 기록(히스토리)을 보고 찾고 정리하는 GUI 관리자 (Linux, 민감 정보 보호 중점)
- [CursorIyagi](https://github.com/iyagicom/CursorIyagi) — AI 가 2모니터(터치)에서 앱을 시험하는 동안 사람의 커서·키보드 포커스를 건드리지 않게 하는 도구 (Linux)
